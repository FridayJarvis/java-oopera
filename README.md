## Описание классов

### Пакет `Shows`

**`Show`** — базовое представление. Хранит название, продолжительность, список актёров и режиссёров. Поддерживает:
- добавление актёра / режиссёра с проверкой на дубликат
- замену актёра с тремя возможными результатами (`SUCCESS`, `OLD_ACTOR_NOT_FOUND`, `NEW_ACTOR_ALREADY_EXIST`)

**`MusicalShow`** — расширяет `Show`. Добавляет либретто и список авторов музыки. Конструктор `protected` — нельзя создать напрямую, только через подклассы.

**`Ballet`** — расширяет `MusicalShow`. Добавляет список хореографов.

**`Opera`** — расширяет `MusicalShow`. Добавляет размер хора.

### Пакет `Workers`

**`Person`** — базовый класс. Хранит имя, фамилию, пол. Переопределяет `equals()`, `hashCode()`, `toString()`.

**`Actor`** — добавляет рост. В `equals()` сравниваются в том числе рост (требование ТЗ). В `hashCode()` рост не участвует — чтобы изменение роста через `setHeight()` не нарушало контракт Java.

**`Director`** — добавляет количество постановок. Аналогичная логика `equals()` / `hashCode()`.

**`AuthorOfMusic`**, **`Choreographer`** — расширяют `Person` без дополнительных полей.

# Самая главная часть, чтобы облегчить жизнь ревьюеру
## Что демонстрирует `main`

Метод `main` последовательно проходит четыре сценария:

1. **Драматический спектакль** («Горе от ума»)  
   Добавление актёров и режиссёров, попытка добавить дубликат.

2. **Балет** («Лебединое озеро»)  
   Добавление актёров, режиссёров, автора музыки (Чайковский), хореографа (Петипа). Два актёра с одинаковыми именем и фамилией, но разным ростом — считаются разными людьми.

3. **Опера** («Князь Игорь»)  
   Добавление участников, установка либретто и размера хора.

4. **Тест замены актёра**  
   Проверка всех трёх результатов `replaceActor`:
    - успешная замена
    - попытка заменить на уже существующего в составе
    - попытка заменить того, кого нет в составе
